<Update label="2026-05-20" description="v1.1.0" tags={["feature"]}>
  ## Free Pod Auto-Provisioning (Phase 5)

  New organizations created via the multi-tenant Studio now get a free Content Pod automatically:

  - **Pod mode selection** — `podMode: 'static' | 'dynamic'` on `CreateOrganizationDto`
  - **Auto-provisioning** — `ContentPodSetupService.setupFreeStaticPod()` / `setupFreeDynamicPod()` called during org creation
  - **Quota enforcement** — free tier: 500 MB storage, 200 items; HTTP 403 on exceed
  - **Quota tiers** — free, starter (5 GB / 5K), pro (20 GB / 50K), enterprise (unlimited)
  - **Admin quota management** — `PUT /manage/content-pod/config` accepts `quotaItemCount` and `quotaStorageBytes`
  - **Onboarding status** — `GET /platform/onboarding/status` returns pod config, quota, and usage

  E2E tested: 57/57 pass (static/dynamic provisioning, publish pipeline, quota 403 enforcement)
</Update>

<Update label="2026-03-17" description="v1.0.1" tags={["feature"]}>
  ## Studio Consumer Integration for Dynamic Features

  **Content Reader integration**
  - roadbeat Studio's Content Reader now automatically detects and renders dynamic pod features (reactions, comments, newsletter) when loading content from a pod
  - Capability detection via `_roadbeat/config.json` — UI sections only appear when the pod explicitly enables them
  - All interactions proxied through Studio's BFF (`POST /discover/pod-proxy`) to avoid CORS issues

  **Documentation**
  - Added "Studio Consumer Integration" section to the Dynamic Features guide covering the pod-proxy architecture, capability detection, supported endpoints, and tip system integration
</Update>
