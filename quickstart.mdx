This guide walks you through creating a Content Pod, generating a signed content bundle, and uploading it to storage.

## Prerequisites

- **Node.js** 20 or later
- **pnpm** 9 or later

## Create a Pod

<Tabs>
  <Tab title="Managed Hosting" icon="cloud">
    Use the Pod Hosting API to create a managed pod on `*.pods.roadbeat.net`:

    ```bash
    curl -X POST https://pods.roadbeat.net/api/v1/pods \
      -H "Authorization: Bearer YOUR_TOKEN" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "My Travel Blog",
        "subdomain": "travel-blog",
        "tier": "free"
      }'
    ```

    Your pod is immediately available at `https://travel-blog.pods.roadbeat.net`.
  </Tab>
  <Tab title="Self-Hosted" icon="terminal">
    Run the full stack locally with Docker Compose:

    ```bash
    git clone https://github.com/roadbeat/content-pod.git
    cd content-pod
    docker compose up -d
    ```

    The Pod Hosting API is available at `http://localhost:3400`, the dashboard at `http://localhost:3401`.
  </Tab>
</Tabs>

## Generate a Content Bundle

<Steps>
  <Step title="Install the generator package">
    ```bash
    pnpm add @roadbeat/content-pod-generator
    ```
  </Step>

  <Step title="Generate an Ed25519 key pair">
    The signing key is used to cryptographically sign every content item for authenticity verification.

    ```typescript
    import { SigningService } from '@roadbeat/content-pod-generator';

    const signing = new SigningService();
    const keyPair = await signing.generateKeyPair();

    // Save keyPair.privateKey securely — never publish it
    // Serve keyPair.publicKey at /public_key.pem on your pod
    ```
  </Step>

  <Step title="Create a content bundle">
    ```typescript
    import { BundleGenerator, TemplateEngine } from '@roadbeat/content-pod-generator';

    const templates = new TemplateEngine();
    const generator = new BundleGenerator(templates);

    const bundle = await generator.generate({
      id: 'article-001',
      contentType: 'news',
      slug: 'hidden-beaches-portugal',
      locale: 'en',
      data: {
        title: '5 Hidden Beaches in Portugal',
        body: '<p>Portugal is famous for its stunning beaches...</p>',
        published_at: '2026-03-01T12:00:00Z',
      },
      media: [],
      author: { name: 'Jane Doe' },
    });

    // bundle.files contains: index.json, index.html, embed.html
    ```
  </Step>

  <Step title="Upload to storage">
    ```typescript
    import { StorageFactory } from '@roadbeat/content-pod-storage';

    const storage = StorageFactory.create({
      type: 'local',
      basePath: './my-pod',
    });

    for (const file of bundle.files) {
      await storage.upload(file.path, file.content);
    }
    ```
  </Step>
</Steps>

## Verify Your Pod

After uploading, your pod directory should look like this:

```
my-pod/
├── manifest.json
├── public_key.pem
└── content/
    └── news/
        └── hidden-beaches-portugal/
            ├── index.json      # Full structured metadata (signed)
            ├── index.html      # Rendered HTML page with SEO tags
            └── embed.html      # Embeddable card for sharing
```

Open `content/news/hidden-beaches-portugal/index.html` in a browser to see the rendered article.
